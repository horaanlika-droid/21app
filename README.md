# 21 — городская ОС · PWA

РПГ-экосистема автономной жизни района. Чёрно-белая 16-битная e-ink эстетика,
пиксель-арт, тёплый бежевый акцент `#d4a373`. Один HTML-файл + папка `assets/`.

## Возможности
- **5 вкладок:** Главная · Карта · Квесты · Энциклопедия · Профиль
- **Квесты** (8 шт., 4 стартовых + расширенные): инструменты, фото/голос, шаги, награды XP/карма/значки
- **25 уровней** с названиями (Новичок → Легенда 21), XP, карма, общий кошелёк
- **Карта Яндекс** (ч/б фильтр, пиксельные маркеры) + пиксельный фоллбэк и добавление точек по геолокации
- **Суд сообщества** — голосование за споры
- **Краудфандинг** — общий кошелёк и AI-распределение бюджета по приоритетам
- **Энциклопедия** — вода, энергия, еда, ремонт, право (статьи, добавление админом)
- **Админ-панель** 🔒 — добавление проблем на карту, постов в ленту, график активности
- **Кастомизация** героя (головные уборы, аксессуары), скаутские значки
- **21-е число** — автоматический «День ресурса» (вода/еда/энергия)
- **AI-агент** — чат по шаблонам (вода, ремонт, книги, суд, общий кошелёк)
- **Стикер с реальным QR-кодом** (генерируется на текущий URL, скачивается в PNG)
- Сохранение всего в `localStorage`, тёмная/светлая тема, офлайн-кэш (service worker)

## Файлы
- `index.html` — всё приложение (CSS/JS встроены; QR-генератор встроен)
- `assets/` — 74 пиксельных PNG (логотип, персонажи, иконки, бейджи, маркеры, текстуры)
- `manifest.webmanifest`, `sw.js` — установка как PWA и офлайн
- `gen_assets.py` — скрипт повторной генерации всех PNG (PIL/Pillow)

## Деплой на GitHub Pages
1. Залейте папку в репозиторий (файл `.nojekyll` уже включён).
2. Settings → Pages → Source: ветка, корень (`/root`).
3. Откроется на `https://<ваш-логин>.github.io/<репо>/`.

> Для Яндекс.Карт задан ключ API. На локальном `file://` карта показывает
> пиксельный фоллбэк; на GitHub Pages по HTTPS работает настоящая карта.

Локально: `python3 -m http.server 8080` → http://localhost:8080
