# 21 — городская ОС

Одностраничное веб-приложение: городской OS-стол «Vista Pixel» для подростков и активных жителей.
Стиль: белый фон, чёрный, серые, акцент `#d4a373`, пиксель-арт, минимум текста — иконки и инфографика.

## Запуск

```bash
# локально (нужен http, не file://)
python3 -m http.server 8080
# → http://localhost:8080
```

Для GitHub Pages: загрузить репозиторий как есть, включить Pages из корня (или вкладки `/docs`).
Относительные пути — без изменений.

## Состав

| Файл | Что |
|---|---|
| `index.html` | Всё приложение: CSS + JS внутри (единый файл) |
| `assets/` | PNG/GIF-заглушки (атлас `atlas.png`, иконки, персонажи, GIF-статусы) — заменяются, имена стабильны |
| `sw.js` | Service worker: офлайн-кэш, автообновление |
| `manifest.webmanifest` | PWA-манифест (белая тема) |
| `tools/qr.js` | QR-кодер (byte mode, EC L, v1–5) — вшит в `index.html` между `/*QR:BEGIN*/…/*QR:END*/` |
| `tools/gen_assets.py` | Генератор пиксель-арт заглушек |

## Что внутри

- **Рабочий стол в стиле Vista**: обои, skyline, облака, иконки, окна (свернуть / развернуть / закрыть,
  перетаскивание), панель задач с ором «Пуск», start menu, тосты, загрузка и «завершение работы».
- **Карта** — Яндекс.Карты (ч/б фильтр, пиксельные маркеры); без сети — статичная пиксель-карта.
- **Квесты** — типы: починить / помочь / обмен / мастер-класс; XP, карма, награды.
- **Профиль** — уровень (кольцо), XP (сегменты), карма (±10), статистика, 8 бейджей.
- **Энциклопедия** — вода, энергия, еда, ремонт; инфографика-шкалы.
- **Кошелёк** — общий краудфандинг: кампании, донаты, **AI-распределение** средств, журнал.
- **Суд** — голосования сообщества: за / против / воздержаться, бары результатов.
- **Лента** — посты; картинки авто-конвертируются в пиксель-арт в палитре приложения.
- **Админ** — проблемы на карте (клик по карте или случайно), посты, сброс данных.
- **Персонаж** — 4 головы + загрузка своего фото (→ пиксель 16×16), 5 аксессуаров, 3 цвета, случайно.
- **Стикеры** — canvas 300×340: персонаж, имя, уровень/карма/XP и **QR-код** (внутренний кодер),
  скачивание PNG.
- **Данные** — только `localStorage` (ключ `os21_v3`), сброс в «Админ» / «21».
- **Мобильная версия** — адаптив, касание открывает окно, окна на весь экран.

## Замечания

- Все картинки — заглушки, генерируются `tools/gen_assets.py` (`python3 tools/gen_assets.py`),
  имена файлов стабильны — заменяйте на свои без правки кода.
- QR поддерживает до ~106 байт (до v5) — этого хватает для стикера.
- Шрифт пиксельных подписей — Press Start 2P (Google Fonts, кириллица), без сети — системный моноширинный.
