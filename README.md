# 21 — районная сеть (Telegram Mini App)

Одностраничное веб-приложение: городская ОС района в формате **Telegram Mini App**.
Стиль: чистый мобильный интерфейс + пиксель-арт в палитре белый / чёрный / серые / `#d4a373`.

## Запуск

```bash
# любой статический сервер
python3 -m http.server 8080
# или точка входа для node-хостинга (без зависимостей, порт — env PORT, по умолчанию 8080)
node http-wrapper.js
# → http://localhost:8080  (кнопка «Войти как разработчик» — полный проход без Telegram)
```

`http-wrapper.js` — минимальный статический сервер (node:http, без npm-зависимостей):
MIME-типы, `Cache-Control` для assets, SPA-фолбэк, защита от path traversal.
`sw.js` безопасен под Node (guard: исполняется только в worker-контексте).

GitHub Pages: включить на репозитории из корня. Для входа через Telegram домен нужно
привязать к боту через **@BotFather → /setdomain** (иначе на гейте «Bot domain invalid»).

## Состав

| Файл | Что |
|---|---|
| `index.html` | Всё приложение: CSS + JS внутри (единый файл) |
| `assets/` | PNG/GIF пиксель-заглушки (имена стабильны — заменяются без правки кода) |
| `http-wrapper.js` | Точка входа для node-хостинга: `node http-wrapper.js` (PORT из env) |
| `sw.js` | Service worker: офлайн-кэш, автообновление (guard под Node) |
| `manifest.webmanifest` | PWA-манифест (белая тема) |
| `tools/qr.js` | QR-кодер (byte mode, EC L, v1–5) — вшит в `index.html` между `/*QR:BEGIN*/…/*QR:END*/` |
| `tools/gen_assets.py` | Генератор пиксель-арт заглушек: `python3 tools/gen_assets.py` |

## Что внутри

- **Вход через Telegram**: имя, ник, аватар (→ пиксель 16×16) из WebApp SDK;
  вне Telegram — гейт «Войти как разработчик» (dev-режим с админ-панелью).
- **Онбординг**: 3 экрана (сосед / как это работает / профиль).
- **Карта района** — Яндекс.Карты: пины квест (синий) / проблема (красный) / решено (серый),
  легенда, статистика, список точек рядом; без сети — пиксель-карта с фолбэк-маркерами.
- **Задачи двора** — типы: починить / помочь / обмен / мастер-класс.
  Взять → в работе → сдать: +XP, +карма, +₽; архив с чипами «решена/твоя».
  «Сообщить о проблеме»: заявка с фото (→ пиксель-арт) и точкой → **на модерацию**, +5 XP +3 кармы.
- **Фонд района** — общий банк, цель квартала, вклады, проекты со срочностью,
  **AI-распределение** (срочность × дефицит × близость к финишу), журнал, последняя раздача.
- **Суд соседей** — голос с весом по карме (1 + карма/50), кворум 12, дела с 2–3 вариантами.
- **Знания** — вода / энергия / еда / ремонт: карточки с цифрами и инфографикой, +3 XP за прочтение.
- **Профиль** — голова (4) + тело (3) + цвет + своё фото (→ пиксель 16×16), статистика,
  прогресс, 8 достижений, выход.
- **Стикер с QR** — canvas: лого 21, QR (глубокая ссылка `…#q={id}` / `…#u={id}`),
  «СКАНИРУЙ · ВОЗЬМИ · СДЕЛАЙ»; печать 60 мм (ч/б), поделиться, скачать PNG.
  QR шифруется внутренним кодером (в `index.html`), декодируется сканерами.
- **Админ-панель** (dev) — модерация заявок (одобрить → точка на карте / отклонить),
  точки, посты в ленту, дела в суд, проекты в фонд, управление лентой.

## Бот: модерация и админ

Telegram-бот (`@twentyonemovementbot`) — канал связи с администрацией района:

- заявка «Сообщить о проблеме» → бот присылает админу сообщение (ник, тип, детали, точка, ID);
- действия админа (одобрение/отклонение, новые точки, посты, дела, проекты, AI-раздача,
  вклады, голоса суда) → логируются ботом в чат;
- Chat ID настраивается в админ-панели: вручную или кнопкой «Найти мой чат»
  (отправить боту `/start` → кнопка поднимет чат через `getUpdates`).

⚠️ Токен бота хранится в `index.html` (статический хостинг, бекенда нет) — виден любому
просматривавшему код. При необходимости токен можно ротнуть через @BotFather.

## Данные

- Все данные — `localStorage` (ключ `os21_v4`): пользователь, квесты, фонд, суд, лента,
  знания, бейджи; сброс — очистить хранилище.
- Шрифты системные (как в Telegram), без внешних зависимостей.
- Пикселизация: любые загруженные фото → палитра приложения (тёплые пиксели → `#d4a373`,
  остальное → 9 градаций серого).
